# Security Policy

## Supported Versions

Only the latest release of Lux Machina receives security fixes. Please check that the
vulnerability still exists in the latest release before reporting it.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public issues, discussions or pull
requests.

Report them privately through
[GitHub private vulnerability reporting](https://github.com/fmargall/luxmachina/security/advisories/new).
If you cannot use GitHub, email [fr.margall@proton.me](mailto:fr.margall@proton.me).

Please include as much of the following as you can:

- the affected versions of Lux Machina;
- a description of the vulnerability and of its impact;
- the steps to reproduce it, ideally with a minimal example;
- any known mitigation or fix.

## What to Expect

Lux Machina is maintained on a best-effort basis. You can expect:

- regular updates while the vulnerability is investigated and fixed;
- a coordinated disclosure: the fix is released before the vulnerability is made public, and
  you are credited in the security advisory, unless you prefer to remain anonymous.
