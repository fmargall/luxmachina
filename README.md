# Lux Machina

[![CI][ci-badge]][ci-workflow]

Differentiable GPU light tracer for optical system design and metrology, built on NVIDIA Warp.

## Installation

```bash
pip install luxmachina
```

Lux Machina requires Python 3.13 or later.

## Usage

```python
import luxmachina

print(luxmachina.__version__)
```
